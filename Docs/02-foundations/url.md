# URL — Notas de Estudo

URL significa **Uniform Resource Locator** e representa o endereço de um recurso.

Exemplo:

```text
https://cleanurl.com/s23B
```

## Componentes principais

### Scheme

`https://`

Define o esquema/protocolo utilizado para o acesso.

### Host/domínio

`cleanurl.com`

Identifica o domínio responsável pelo recurso.

### Path

`/s23B`

No CleanURL, o path público poderá conter o ShortCode utilizado para localizar o destino.

## ShortURL x LongURL

A LongURL é o destino original. A ShortURL é uma referência pública criada pelo CleanURL. O sistema não altera a LongURL; ele cria um identificador que permite localizá-la.
