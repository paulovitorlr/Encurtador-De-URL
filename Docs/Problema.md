Para o que serve?

Um encurtador serve para deixar enxuta uma URL gigantesta, mais "agradável" aos olhos.
Em alguns casos, dá para monitorar quantidade de clicks e horário de picos.

Funcionamento padrão de um encurtador:

Cliente coloca um link longo
Banco de dados registra e cria um Id unico para a sessão.
Geração de Link utilizando o dominio do link longo + o codigo
Redirecionamento para o site original

Muito bom para sistemas que contém limites de caracteres.
