Url (Uniform Resource Locator)

É o endereço exclusivo usado para localizar e acessar conteúdos na web.

Partes principais de uma URL

Protocolo: o metodo de comunicação no inicio do texto, algo como: https://. indica que os dados trafegam de forma segura.

Dominio: O nome principal do site (por exemplo Facebook), ele substitui o endereço numérico de IP.

Caminho (Path): A pasta ou página exata dentro do servidor (/produtos/item).
